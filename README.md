## Context Slicing — chapters at a glance

1. The mathematics of context rot (quadratic attention, KV-cache physics, lost-in-the-middle)
2. Four terminal harness anti-patterns, autopsied with measurements
3. The Context Slicing doctrine: ASTs over character streams
4. The 4-tier parsing-tree protocol (topology → AST → zero-read capture → 3-witness verify)
5. The RTK action proxy and the banned-POSIX mandate
6. Code intelligence: `sg` + bounded reads
7. Discovery: `rg`, `fd`, `erd`
8. Mutation and diff: `sd`, `rnr`, `difft`
9. Structured data and observability: `jaq`, `dasel`, `dust`, `procs`, `xh`
10. Lifecycle and benchmarking: `just`, `hyperfine`, Kavach gates
11. Kavach sovereign governance and the 5 fail-closed gates
12. Mechanical sympathy: zero-heap layouts, cache lines
13. Three-witness verification and WAL persistence
14. Migration economics: the Hormozi value equation for agent teams
